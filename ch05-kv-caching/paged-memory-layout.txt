+------+------+------+------+------+------+------+------ ...
|Block0 |Block1 |Block2 |Block3 |Block4 |Block5 |Block6 |...
|K,V,K,V|K,V,K,V|K,V,K,V|K,V,K,V|K,V,K,V|K,V,K,V|K,V,K,V|...
+------+------+------+------+------+------+------+------ ...

Logical Request Sequences:
Request A (seq_id=0):  [Block0] -> [Block1] -> [Block2] -> ...
Request B (seq_id=1):  [Block3] -> [Block4] -> ...
Request C (seq_id=2):  [Block5] -> [Block6] -> ...
Free:                   [Block7] -> [Block8] -> ...

Block Table for Request A:
  Logical block 0 -> Physical Block 0
  Logical block 1 -> Physical Block 1
  Logical block 2 -> Physical Block 2
